# Micromouse

Autonomous maze-solving robot based on STM32F411CEU6.

## Hardware

- MCU: STM32F411CEU6
- Motor Driver: DRV8833
- Distance Sensors: 5x VL53L0X
- IMU: ICM-20602
- Motors: Dual DC motors with quadrature encoders

## Development

- Language: C
- Framework: STM32Cube HAL
- Build System: PlatformIO
- Testing: Unity, Native Simulation
- Version Control: Git / GitHub
